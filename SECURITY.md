# Working safely with your course repository

Use only the included synthetic training dataset. Keep account passwords,
access tokens, personal information and private Drive files out of your project
repository, notebook outputs and screenshots.

Sign in to Google and GitHub through their own interfaces. The course notebooks
do not ask you to paste an access token into a code cell. Your local Kafka
broker listens on loopback and does not need a public endpoint.

The daily GitHub ZIP is for small project evidence. The full handoff ZIP belongs
in your own Drive folder. Review both before sharing. If you accidentally expose
a credential, revoke it through the service and notify the instructor privately;
removing a visible line does not remove it from Git history.

For a course code issue, share the day, cell and redacted error through the
instructor's announced channel. Do not include credentials or personal data.
