# Optional distinction extensions

[Course home](../README.md) · [Start here](../docs/START_HERE.md) · [Execution record](../STATUS.md)

## Not required

These are optional extensions after the core is complete. Doing none does not make the core project incomplete. They are not a separate graded project and their presence does not imply an extra grade or certificate entitlement.

## Bounded extensions

- Add a clearly scoped data-contract test to one Gold table.

- Compare an alternative quality threshold on a copied synthetic scenario.

- Document an additional recovery test without adding a paid service.
