# Sources and attribution

Read the [course source register](docs/SOURCES.md) for the primary documentation
used in the lessons, labs and slides. Each presentation also includes links to
its relevant technical sources.

This course adapts the [original Masar engineering repository](https://github.com/almiyead-rgb/masar-modern-data-engineering)
into a five-evening learning experience for King Saud University students.
The original repository retains its development history and authoring tools.
The learning objectives are mapped in the [alignment guide](docs/ALIGNMENT.md).

The portal's guided onboarding and local comparison workflow were informed by
[Rafeeq Agentic AI Labs](https://almiyead-rgb.github.io/rafeeq-agentic-ai-labs/).
Masar uses its own five-day curriculum, cumulative project and assessment policy.
