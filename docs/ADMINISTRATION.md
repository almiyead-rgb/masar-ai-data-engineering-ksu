# Course administration

This page records delivery decisions. Students should use the [start guide](START_HERE.md) and [certificate policy](../assessment/CERTIFICATES.md).

## Fixed decisions

- Five evenings, 17:00–21:00 in Asia/Riyadh.
- Twenty slides per day; 100 in total.
- 150 minutes of explanation/demonstration/activity, one 60-minute lab and two 15-minute prayer breaks each day.
- Google Colab is the student execution environment.
- One cumulative project and one individual repository per student, with daily saves.
- Project marked out of 100; attendance is a separate condition.
- All five days plus a project score of at least 70 earns a completion/pass certificate.
- All five days with no project or a project below 70 earns an attendance certificate only.

## Teaching and review

Use the [rubric](../assessment/RUBRIC.md) and retained execution evidence. Review small student-authored tasks and explanations in addition to output counts. Similar output values are expected because everyone uses the same fixed fixture. Allow discussion and pair assistance while keeping individual evidence.

Freeze the teaching release before the cohort. A necessary fix must include a clear migration note so students do not overwrite their own work. Keep the source version, input manifest and runtime record alongside reference results.
