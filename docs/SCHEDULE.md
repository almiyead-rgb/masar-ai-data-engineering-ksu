# Five-evening schedule

**17:00–21:00, Asia/Riyadh.** Course dates are confirmed by the organizer.

| Daily component | Minutes |
|---|---:|
| Concepts, demonstrations, discussion and a five-minute activity | 150 |
| Project lab, daily question and saving | 60 |
| Maghrib prayer break | 15 |
| Isha prayer break | 15 |
| Total | 240 |

The instructor places both prayer breaks according to the actual dates. Keep the full 60-minute lab; move its position when a prayer time would interrupt it. Scheduled attendance totals 20 hours. Explanation totals 12.5 hours and labs total five hours, giving 17.5 learning hours.

## Your lab hour

| Part | Minutes |
|---|---:|
| Run the guided tasks and inspect checks | 45 |
| Write your own answer to the daily question | 5 |
| Discuss the model answer and add a correction if needed | 5 |
| Save the notebook, evidence and handoff | 5 |

Account sign-in and an initial save trial are part of preparation. Runtime setup is demonstrated before the practical work; actual setup/run/save time must fit the tested delivery plan. The instructor uses the execution timing record to identify any stage that needs preloading or simplification without removing its learning objective.

## Slide structure

| Slides | Purpose |
|---|---|
| 1–2 | Project context and the day's outcomes |
| 3–8 | Concepts connected to the project |
| 9–10 | Quick activity and answer |
| 11–16 | Worked examples, code reading and demonstrations |
| 17–18 | Lab task, expected results and saving |
| 19–20 | End-of-lab question and model answer |

Each day has exactly 20 slides, including its cover/context. The lab is a stage of the same cumulative project. The final day completes and submits that project.
