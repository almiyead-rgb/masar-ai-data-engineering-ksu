# Start here

You will build one project over five days. Use one repository for all your work and continue in order.

## Before your first lab

1. Sign in to a Google account that can use Google Colab and Drive.
2. Sign in to GitHub. Open the course repository and select **Fork** to create your own copy.
3. Read [the project brief](../project/README.md) and [assessment policy](../assessment/CERTIFICATES.md).
4. Open [Day 1 in Colab](https://colab.research.google.com/github/almiyead-rgb/masar-ai-data-engineering-ksu/blob/main/day01/STUDENT.ipynb).
5. Run the setup cells and read the runtime report. Follow [setup](SETUP.md) if a version check stops.
6. Save a copy of the notebook to your repository and confirm that you can see it on GitHub.

You need a browser, internet access and storage for your daily handoff archive. The labs target CPU execution and do not require an LLM API, a GPU or a paid external data service. Colab resource availability can vary, so follow the recovery instructions if your session ends.

## Your daily learning loop

**Understand the problem. Run the code. Inspect the result. Explain the decision. Save the evidence.**

Each day has a concepts guide, 20 slides, one main notebook, step-by-step lab walkthroughs, a glossary, one quick activity and one assessed reflection. The additional discussion prompts are optional practice unless your instructor uses them in class.

Use the source files unchanged. A reference result helps you compare your work; it does not replace your own execution or explanation.

## First successful checkpoint

Before continuing, confirm that you can open your own repository, open the notebook in Colab, run a code cell and save its output. For the first daily handoff, also confirm that the ZIP exists in your Drive folder.
